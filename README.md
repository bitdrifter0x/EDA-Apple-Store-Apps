# 🍎 Apple App Store — SQL Exploratory Data Analysis

A data analysis project using SQL to explore trends in Apple App Store data, uncovering what drives higher user ratings and app success.

---

## 📌 Overview

This project queries Apple App Store datasets using SQL to answer key business and product questions. By analyzing ratings, pricing, language support, genres, and description quality, the project identifies patterns that distinguish high-performing apps from the rest.

---

## 🔍 Key Analyses

| # | Analysis |
|---|----------|
| 1 | **Ratings Overview** — Distribution and summary statistics of app ratings across the store |
| 2 | **Paid vs. Free Apps** — Whether paid apps receive higher average ratings than free apps |
| 3 | **Language Support** — Impact of the number of supported languages on user rating |
| 4 | **Lowest Rated Genres** — Genres consistently receiving the poorest user ratings |
| 5 | **Description Length vs. Rating** — Correlation between app description length and user rating |
| 6 | **Top Rated Apps per Genre** — Highest rated app in each genre using ranking queries |
